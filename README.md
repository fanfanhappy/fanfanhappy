### [TraceFind · 寻迹](https://github.com/fanfanhappy/TraceFind)

**忘了文件名，记得一点也能找。**

Windows 本地文件搜索，一个输入框同时搜文件名、拼音、正文、OCR 和语义。

- 扫描件里的字也能搜到，结果标清来源
- 找到直接预览，也能对着文件提问
- 单文件安装、可选目录，数据不出本机

<sub>Rust · Tauri 2 · React 19 · SQLite/FTS5 · 本地语义模型</sub>

[下载安装](https://github.com/fanfanhappy/TraceFind/releases/latest) ·
